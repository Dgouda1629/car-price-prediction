# car-price-prediction
Car price prediction using machine learning
Car Price Prediction
Overview

This project predicts the selling price of used cars using machine learning regression techniques.
An interactive Streamlit web application allows users to enter car details and get real-time price predictions.

Problem Statement

Used car prices vary based on factors like age, mileage, engine capacity, fuel type, and transmission.
The goal is to build a model that estimates a fair market price using historical data.

Solution

Data cleaning and preprocessing

Feature encoding for categorical variables

Model training using Multiple Linear Regression

Model evaluation using RMSE, MAE, and R² Score

Deployment using Streamlit
